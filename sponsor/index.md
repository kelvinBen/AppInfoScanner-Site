# 赞助与捐赠

AppInfoScanner 是 GPL-3.0 开源项目（3500+ Stars），由个人开发者在业余时间持续维护——实战反馈修复、规则库扩充、三平台工具链供给都依赖这些投入。如果它在你的工作里帮上了忙，欢迎通过以下方式支持项目继续演进。

## 广告位（面向安全厂商 / 社区）

官网下载中心提供**自营广告位**（赞助商形式，非联盟广告），数据驱动投放、可随时上下线：

| 位置 | 形态 | 说明 |
| --- | --- | --- |
| 下载中心页首 | 横幅 | 进入下载路径的第一视觉位 |
| 下载中心卡间 | 卡片 | 与工具卡 / 主程序卡混排 |
| 全站页脚 | 文字链 | 所有页脚常驻露出 |

- **形式**：图片 + 跳转链接（`rel="noopener sponsored"` 合规标注），或纯文字链。
- **受众**：红队 / 渗透测试 / 企业安全建设工程师，访问目的明确（下载工具、查规则）。
- **政策**：仅接受安全行业相关（厂商、培训、社区、会议）；博彩、灰产、违法内容一律不接。
- **价格与排期**：联系作者商定（见页尾联系方式）。

## 捐赠（面向个人用户）

- **爱发电**：链接待开通（作者开通后第一时间更新至此）
- **收款码**：微信 / 支付宝收款码待补充
- **GitHub Sponsors**：点击主仓库右上角 **Sponsor** 按钮进入本页
- **零成本支持**：给 [主仓库](https://github.com/kelvinBen/AppInfoScanner) 点一个 **Star**、把工具推荐给同事、给[规则中心](/rules/)补一条规则、投一篇[使用好文](/articles/)——这些都同样重要。

## 赞助会用在哪儿

- 工具链分发带宽与 Release 资产托管
- 多平台测试设备与真机适配（脱壳 / 嗅探链路）
- 文档站与规则库的持续维护
