# V1.0.0 版本说明

> 发布于 2020 · 该版本未打发布 tag，请从最新版本开始（见[下载中心](/tools/)） · [更新日志总览](/changelog/)

- 支持目录批量扫描
- 支持 DEX、APK、Smali、HTML、JS 等文件的静态资源采集
- 支持自定义扫描规则
- 支持 IP 地址信息采集
- 支持 URL 地址信息采集
- 支持中间件信息采集
- 支持多线程
- 支持忽略资源文件采集
