# About

## Project

AppInfoScanner is a mobile (Android, iOS, WEB, H5, static sites) information-gathering scanner for HW operations / red team / penetration testing teams. It helps pentesters, attack team members, and red teamers quickly collect key asset information from mobile apps or static web bundles, providing basic information output such as: Title, Domain, CDN, status info, etc.

The developer is an individual developer with a full-time job; new features are developed in spare time, and bugs are prioritized. For problems or feature requests, please submit them at [issues](https://github.com/kelvinBen/AppInfoScanner/issues) (read the [FAQ](/en/faq) first).
