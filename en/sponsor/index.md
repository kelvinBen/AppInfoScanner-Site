# Sponsor & Donate

AppInfoScanner is a GPL-3.0 open-source project (3500+ stars) maintained by an individual developer in spare time — field-feedback fixes, rule-set expansion and three-platform toolchain provisioning all depend on that effort. If it helps your work, consider supporting the project.

## Ad Placements (for security vendors / communities)

The site offers **self-operated sponsor slots** (sponsor-style, not ad networks) on the download center, data-driven and switchable anytime:

| Placement | Format | Notes |
| --- | --- | --- |
| Downloads page top | Banner | First visible spot on the download path |
| Downloads card grid | Card | Mixed with tool / program cards |
| Site footer | Text link | Persistent across pages |

- **Format**: image + link (marked `rel="noopener sponsored"`), or plain text link.
- **Audience**: red team / pentest / corporate security engineers with clear intent (downloading tools, browsing rules).
- **Policy**: security-industry related only (vendors, training, communities, conferences); gambling, gray-market or illegal content is rejected.
- **Pricing & schedule**: contact the author (see below).
